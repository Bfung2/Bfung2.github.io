# Business policy decisions — not published customer terms

These decisions need the owner's approval before customer-facing policies can be written or published. No durations, fees or promises are assumed here.

| Topic | Owner decision needed |
| --- | --- |
| Assembly warranty | Coverage period, covered work, exclusions, and how customers request support |
| Parts warranty | How manufacturer warranties and Apex assistance are handled |
| Returns | Whether parts, opened items and custom builds are eligible; time window and condition requirements |
| Refund amounts | Treatment of assembly labor, shipping and any approved fees |
| Defective / damaged deliveries | Contact process and evidence customers should provide |
| Shipping | Service area, available methods, charges, and how estimates are communicated |
| Pickup | Location/contact process and how customers arrange collection |
| Build turnaround | When estimates start, normal range, and how delays are communicated |
| Cancellation | When an order can be cancelled and what happens once parts/work are underway |

A reviewable policy wording draft is in `docs/customer-policy-draft.md`. Secure customer account code is prepared; public signup still requires the email setup and activation checks in `docs/customer-account-setup.md`. Private receipt links remain available.
